La file « à comptabiliser »

L'onglet À comptabiliser regroupe tout ce que l'accueil a fait et qui attend son écriture, en cinq tableaux : annulations, règlements de créances, abandons de dettes, remboursements et remises de chèques. Le bouton Comptabiliser d'une ligne crée l'écriture correspondante, équilibrée, et le message de confirmation propose un lien vers elle.

La page est visible dès le droit comptabilité : lecture, pour que l'accueil puisse voir ce qui reste ; les boutons demandent comptabilité : écriture. Si la comptabilisation automatique est activée, la file ne contient plus que ce qui n'a pas pu être passé tout seul.

L'écriture de chaque opération

Les comptes ci-dessous sont ceux par défaut ; tous se changent dans la configuration. Chaque écriture est une écriture « avancée », rattachée aux membres concernés, ce qui la fait apparaître dans Comptes de membres.

La recette n'est jamais annulée. Un chèque impayé ne défait pas la vente : la somme passe du compte d'attente à la créance du membre. Ce qui en advient ensuite (règlement, abandon) a sa propre écriture.

Chaque écriture porte la date de l'opération, pas celle du clic sur Comptabiliser : on peut comptabiliser des semaines plus tard sans fausser les dates. L'écriture va dans l'exercice qui couvre cette date, qui doit donc être encore ouvert.

La comptabilité reste maîtresse

Une écriture créée par le module reste une écriture ordinaire : elle se modifie et se supprime normalement. Le module ne relit jamais son contenu : il vérifie seulement qu'elle existe encore. Si elle est supprimée, l'élément réapparaît dans la file, prêt à être repassé.

Côté accueil, une écriture passée verrouille ce qu'elle reflète : un chèque dont l'annulation est comptabilisée n'est plus modifiable, un bordereau comptabilisé ne peut plus être annulé, un remboursement comptabilisé ne peut plus être supprimé. Pour corriger, supprimer d'abord l'écriture.

Contrôler les comptes

Quand tout est comptabilisé :

  • le solde du 5112 correspond aux chèques reçus qui ne sont ni déposés ni annulés : ceux « À encaisser » et « Dans un lot » dans le module ;
  • le solde du 411 d'un membre correspond à sa créance dans l'onglet Impayés.

L'onglet Impayés fait lui-même une partie de ce contrôle : si la comptabilité porte sur les comptes de membres des mouvements que le module n'a pas créés (une cotisation saisie à la main, par exemple), un encadré annonce l'écart, pour qu'on ne prenne pas la liste pour exhaustive.

Que faire si…

… le bouton Comptabiliser renvoie une erreur ?
Le plus souvent, aucun exercice ouvert ne couvre la date de l'écriture, ou un compte configuré n'existe pas dans le plan comptable de cet exercice. L'élément reste dans la file : il suffit de recommencer une fois le problème réglé.
… j'ai supprimé une écriture par erreur ?
L'élément est revenu dans la file : le comptabiliser à nouveau.
… l'accueil doit corriger un chèque déjà comptabilisé ?
Supprimer l'écriture concernée : la fiche redevient modifiable, et l'élément revient dans la file une fois corrigé.
… un chèque revient impayé après avoir été déposé ?
Le module ne le gère pas : passer l'écriture du rejet à la main, à partir du relevé bancaire, en liant le membre.
… on clôture l'exercice ?
Rien de particulier pour le module, qui ne dépend pas de l'exercice : les chèques et les dettes continuent leur vie. Mieux vaut seulement avoir vidé la file avant la clôture.
