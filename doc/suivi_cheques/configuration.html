La configuration est réservée aux administrateurs. Elle se fait une fois, au démarrage, et ne se touche plus guère ensuite.

Pré-requis

  • L'extension Caisse est activée, avec un moyen de paiement par mois d'encaissement : « Chèque janvier », « Chèque février »… de type « Suivi ».
  • Un exercice comptable ouvert, pour que les écritures puissent être passées.
  • Le module Bordereau de remise en banque fourni avec Paheko est désactivé : ce module produit ses propres bordereaux et ses propres écritures de remise, les deux se marcheraient dessus.

Le compte d'attente doit être celui que les moyens de paiement « chèque » de la caisse débitent. Les deux comptes d'abandon peuvent être le même si la distinction ne sert pas à la comptabilité. Le détail des écritures est sur la page Comptabilité.

Moyens de paiement et mois

Chaque moyen de paiement de type « Suivi » de la caisse est listé ; on lui associe le mois où ses chèques partent en banque, ou « — » s'il n'est pas encaissé en différé. Seuls les chèques d'un moyen relié à un mois sont suivis par le module.

L'année n'est pas à indiquer : un chèque part au prochain mois de ce nom après sa réception (voir le mois d'encaissement).

Comptabilisation automatique

Par défaut, le module prépare les écritures et la comptabilité les valide dans la file « à comptabiliser ». Trois cases suppriment cette attente : le module passe alors l'écriture lui-même, au moment de l'opération.

  • les annulations, dès que l'annulation est enregistrée ;
  • les règlements, abandons de dettes et remboursements, dès qu'ils sont enregistrés ;
  • les remises, dès que le bordereau est marqué déposé.

Comme le réglage équivalent de la caisse, c'est la case cochée par l'administrateur qui vaut autorisation : l'écriture est passée même si la personne qui fait l'opération n'a aucun droit en comptabilité.

Sur les annulations, la fiche se verrouille aussitôt. L'écriture étant passée immédiatement, le chèque n'est plus modifiable. Pour corriger, supprimer l'écriture en comptabilité : le chèque redevient modifiable.
Un échec ne fait rien perdre. Si l'écriture ne peut pas être créée (aucun exercice ouvert ne couvre la date, compte inexistant…), l'opération est quand même enregistrée, un message le signale, et l'élément reste dans la file « à comptabiliser ».

Qui peut faire quoi

Le module suit les droits des catégories de membres de Paheko : il vit dans la section Membres, et ses écritures relèvent de la section Comptabilité.

DroitCe qu'il permet
Membres : lectureouvrir le module, voir les chèques, les bordereaux, les impayés, l'encart de la fiche membre
Membres : écrituretout ce que fait l'accueil : modifier et annuler des chèques, constituer et déposer des bordereaux, encaisser, abandonner, rembourser
Comptabilité : lecturevoir la file « à comptabiliser »
Comptabilité : écriturepasser les écritures depuis la file
Configuration : administrationla page de configuration

L'accueil a typiquement membres : écriture et comptabilité : lecture ; la comptabilité, l'inverse.

Mettre à jour le module

Pour installer une nouvelle version, importer l'archive depuis Configuration › Extensions en cochant la case qui écrase le module existant. Les données du module (chèques, bordereaux, dettes) sont conservées.

Ne jamais supprimer le module pour le réinstaller. Supprimer un module efface toutes ses données : annulations, bordereaux, créances, règlements. Si l'import refuse parce que le module existe déjà, c'est seulement la case à cocher qui manque.
